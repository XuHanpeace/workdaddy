# Workdaddy

工作问题都找 Workdaddy，让我成为你的赛博 Daddy。

需求来了别慌，报错来了别跑。你负责说清楚想干什么，Workdaddy 负责努力把活儿干明白。

这是一个正在施工中的桌面 Coding Agent：希望接住你的工作难题，而不是接管你的人生。毕竟，真正的 Daddy 应该帮你下班，不是劝你加班。

## 打算替你操哪些心？

- **读代码**：项目太大不想翻？先让 Daddy 看看。
- **改代码**：少一点复制粘贴，多一点工具调用。
- **跑命令**：验证结果靠执行，不靠一句“应该没问题”。
- **记进度**：聊到哪、做到哪，尽量不当赛博金鱼。
- **守边界**：该审批的先问，该看的 diff 给你看。名字叫 Daddy，权限还是你最大。

以上是产品目标，不是已交付功能清单。目前刚完成仓库初始化，Daddy 还在学走路，暂时不能替你上班。

## Daddy 的装备清单

- Electron + React + TypeScript。
- 开源 Agent 内核：评估 Pi、Mastra 等方案后决定。轮子可以借，原理必须懂。
- 模型服务：优先验证 DeepSeek 接入。
- 存储：SQLite；通信：类型化 Electron IPC。


## MVP 目标

- 选择本地工作区，通过聊天提交代码任务。
- 展示模型流式回复、工具调用及任务状态。
- 支持会话保存、任务取消与上下文管理。
- 提供操作审批及代码变更 diff。
- 完成桌面打包，并通过固定任务集验证效果。

## 家规不多，但得有

- `master` 保存通过验收的稳定成果。
- 功能开发使用 `feat/` 开头的分支，一次认真做好一件事。
- API Key 留在本地配置里。Daddy 可以公开，密钥不行。
- 当前尚无可运行应用，启动命令会在完成脚手架后补充。
