# Workdaddy

基于开源 Agent 内核构建的桌面 Coding Agent 学习项目。目标是完成可演示的 MVP，理解桌面交互、模型调用、工具执行、会话管理与权限控制的完整链路。

## 技术方向

- Electron + React + TypeScript。
- 开源 Agent 内核：第一周评估 Pi、Mastra 等方案后决定，不直接迁入自研 Harness。
- 模型服务：优先验证 DeepSeek 接入。
- 存储：SQLite；通信：类型化 Electron IPC。

当前仅初始化仓库与计划，尚未搭建应用或安装依赖。

详见 [周计划](docs/weekly-plan.md)。

## MVP 目标

- 选择本地工作区，通过聊天提交代码任务。
- 展示模型流式回复、工具调用及任务状态。
- 支持会话保存、任务取消与上下文管理。
- 提供操作审批及代码变更 diff。
- 完成桌面打包，并通过固定任务集验证效果。

## 开发约定

- `master` 保存通过验收的稳定成果。
- 功能开发使用 `feat/` 开头的分支，按周计划推进。
- API Key 通过本地环境配置，不提交到仓库。
- 当前尚无可运行应用，启动命令会在完成脚手架后补充。
